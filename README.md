# 📚 Planner Pedagógico

Sistema web para organização educacional, permitindo que professores e supervisores gerenciem turmas, disciplinas, planejamento e avaliações em um único ambiente.

---

## ✨ Visão Geral

O **Planner Pedagógico** foi desenvolvido para centralizar tarefas essenciais do dia a dia docente, reduzindo a fragmentação entre ferramentas e melhorando a gestão pedagógica.

A aplicação permite organizar informações acadêmicas de forma simples, visual e eficiente, com foco na produtividade do professor.

---

## 🚀 Funcionalidades

### 🔐 Autenticação
- Login com e-mail e senha  
- Cadastro com validação de dados  
- Recuperação de senha  
- Persistência de sessão  

### 👩‍🏫 Gestão de Usuário
- Cadastro de professores e supervisores  
- Perfis com nome, username e tipo de usuário  

### 🏫 Turmas
- Criação de turmas  
- Listagem de turmas  
- Exclusão de turmas  
- Visualização detalhada  

### 📘 Disciplinas
- Associação de disciplinas às turmas  
- Definição de carga horária semanal  
- Remoção de disciplinas  

### 🧠 Funcionalidades em evolução
- Registro de presença (chamada)  
- Planejamento diário  
- Sistema de avaliações e notas

## 🛠️ Tecnologias Utilizadas

- HTML5  
- CSS3 (com variáveis e suporte a tema)  
- JavaScript Vanilla  
- Supabase (autenticação e banco de dados)  (provavelmente não estará ativo, pois o projeto está suspenso no Supabase por falta de uso)

## 🎨 Design e Experiência

- Interface moderna e minimalista  
- Paleta elegante (vinho + dourado)  
- Tipografia refinada (Cinzel + Inter)  
- Suporte a tema claro e escuro  
- Persistência de preferência do usuário  

---

## ⚠️ Pontos de Atenção

- Algumas validações ainda estão apenas no front-end  
- Dependência de dados como `school_id` pode gerar inconsistências  
- Feedback ao usuário pode ser melhorado (ex: evitar uso de `alert`)
